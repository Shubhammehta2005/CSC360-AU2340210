## Maven project

A Maven project has a fixed kind of structure, which makes it easier to manage.
![alt text](image.png)
this is its folder structure where project is named first_project

`src/main/java` is resident of actual java code

`src/main/resources` is for things like assets like images or config files.

`src/test` contains testing code.

`target` is generated by Maven, so we dont normally edit anything there.

The `pom.xml` is basically the main configuration file for Maven.

It contains things like project name and version, java version, dependencies, plugins, build settings

Some basic Maven commands are:

```text
mvn clean
mvn compile
mvn test
mvn package
```

So Maven makes building the project more consistent instead of manually setting everything up.
Now drawing a square,

To draw a square, we mainly need its length and exact location

If the side is `s`, then:  length and width both will be s

If we know the center `(cx, cy)`, the top-left point can be found by:

```text
x = cx - s/2
y = cy - s/2
```


The four corners can then be calculated from this point.

```text
top-left     = (x, y)
top-right    = (x+s, y)
bottom-left  = (x, y+s)
bottom-right = (x+s, y+s)
```

We use following codeblock for drawing square in same way:
```java
g2d.drawRect(x, y, s, s);
```
or for a filled square,

```java
g2d.fillRect(x, y, s, s);
```

### Java Coordinates


The `(0,0)` point is at the **top-left** so it is considering 4th quadrant.

So x increases towards the right and y increases downwards.

If we want the square in the middle of a panel, we can calculate:

```java
int x = (getWidth() - side) / 2;
int y = (getHeight() - side) / 2;
```

This also helps when the window size changes.


## Java graphics

### AWT

AWT is the older Java GUI toolkit. It provides basic windows, buttons, events and graphics.

Some classes are:

```text
Frame
Button
Graphics
Color
```

### Swing

Swing is built using AWT and has more GUI components.

Examples:

```text
JFrame
JPanel
JButton
JLabel
```

Usually `JFrame` is the window and `JPanel` is used for putting things or drawing.

Swing also uses the **Event Dispatch Thread**, so GUI related work should generally happen on that thread.

### Java2D

Java2D is mainly what we use for actual drawing.

It can draw:
- Lines
- Rectangles
- Circles
- Text
- Different colors
- Rotations and scaling

For custom drawing, we usually override:

```java
paintComponent(Graphics g)
```

and use `Graphics2D` inside it.

We also call:

```java
super.paintComponent(g);
```

so the panel gets properly cleared before drawing again.

### JavaFX

JavaFX is another framework for making Java GUI applications. It has things like CSS styling, animations, effects and scene graphs.

Unlike AWT and Swing, JavaFX is not included in the normal JDK anymore and is handled separately.
