## Jframe
Jframe is a top level window and class provided by Swing for a desktop Java application

```java
import javax.swing.JFrame;
JFrame frame = new JFrame("My Application");
```
this will create a jframe object with title my application
And we use the *setVisible()* method to make it visible.
Other methods like *setSize()* help define the window dimensions.

## OOP Concepts
```java
class DrawingPanel extends JPanel {

    @Override
    protected void paintComponent(Graphics g) {
        super.paintComponent(g);

        Graphics2D g2d = (Graphics2D) g;

        g2d.drawRect(100, 100, 200, 200);
    }
}
```

Consider the code above.
OOP concepts include:
- Inheritance
    + Drawing Panel is a subclass of Jpanel
    + *extends* defines inheritance
- is-a relationship
- polymorphism
    + One reference/type can represent different actual objects
    + so actual object is DrawingPanel but variable is declared of type Jpanel
    +upcasting basically
